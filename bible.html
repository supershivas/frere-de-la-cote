1. Philosophie de Design

Vision

L'interface de Frères de la Côte doit évoquer :

  • Une carte de navigateur : lisible, précise, authentique.
  • Un journal de bord : texturé, chaleureux, immersif.
  • Un combat tactique : clair, anticipable, satisfaisant.

Principes fondamentaux

PrincipeDescriptionApplication
Lisibilité avant toutChaque information doit être visible en 1 secondeContraste élevé, hiérarchie claire, pas de surcharge
Immersion constanteL'UI ne casse jamais l'ambiance pirateCouleurs sombres, textures bois/parchemin, pas de blanc pur
Feedback immédiatChaque action a une réponse visuelleAnimations, sons, toasts, particules
AnticipationLe joueur doit prévoir les conséquencesIntentions ennemies visibles, stats transparentes
Cohérence totaleMême langage visuel sur tous les écransMêmes couleurs, mêmes composants, mêmes animations

  --gold-dark: #b8860b;     /* Or ombre, profond */
  --gold-glow: rgba(212, 160, 23, 0.4);

  /* === VIE & DÉGÂTS === */
  --hp: #e74c3c;            /* Points de vie */
  --hp-dark: #c0392b;       /* PV bas, critique */
  --hp-bg: #1a1210;         /* Fond barre PV */

  /* === BOUCLIER === */
  --shield: #3498db;        /* Bouclier actif */
  --shield-dark: #2980b9;   /* Bouclier faible */

  /* === ARMURE === */
  --armor: #95a5a6;         /* Armure, métal */
  --armor-light: #bdc3c7;   /* Armure highlight */

  /* === ÉTATS === */
  --success: #2ecc71;       /* Succès, soin, gain */
  --danger: #e74c3c;        /* Danger, dégâts, mort */
  --warning: #f39c12;       /* Attention, feu, orage */
  --info: #3498db;          /* Info, eau, glace */

  /* === TEXTES === */
  --text-primary: #f5f5dc;  /* Blanc cassé, parchemin (JAMAIS #FFFFFF) */
  --text-secondary: #95a5a6;/* Gris clair, descriptions */
  --text-muted: #888888;    /* Gris, inactif, hint */
  --text-dark: #1a1210;     /* Texte sur fond clair/or */

  /* === BORDURES === */
  --border: #5a3d25;        /* Bordure standard (bois) */
  --border-light: #d4a017;  /* Bordure active/or */
  --border-enemy: #e74c3c;  /* Bordure ennemi */
  --border-disabled: #444444;/* Bordure inactif */
}
Règles d'or :
  1. Jamais de blanc pur (#FFFFFF) — toujours --text-primary (#f5f5dc).
  2. Jamais de noir pur (#000000) — toujours --bg-dark (#0d0908).
  3. Or pour l'accent : sélection, récompenses, titres.
  4. Rouge uniquement pour danger : dégâts, mort, ennemis.
  5. Vert uniquement pour succès : soin, gain, alliés.

Règles typographiques

  • Nombres : toujours en monospace pour l'alignement.

  • Texte de lore : IM Fell English italic, --text-muted.
  • Logs de combat : Courier Prime, couleur selon faction.

--ease-fast: cubic-bezier(0.4, 0, 0.2, 1);     /* Standard Material */
--ease-bounce: cubic-bezier(0.68, -0.55, 0.265, 1.55); /* Bounce léger */

8.3 Animations clés & Sprite Sheets

Sélection de bateau :

@keyframes select-pulse {
  0%, 100% { box-shadow: 0 0 10px rgba(212, 160, 23, 0.3); }
  50%      { box-shadow: 0 0 20px rgba(212, 160, 23, 0.6); }
}
.ship-card--selected {
  animation: select-pulse 2s ease-in-out infinite;
}
Note technique pour les sprite sheets (effets) :
Pour les animations d'effets (ex: fx_explosion.png), utiliser impérativement animation: nom steps(X) infinite (où X est le nombre de frames) sur la propriété background-position. Cela garantit un rendu pixel art net, sans interpolation fluide entre les frames.

12. Accessibilité

12.1 Contraste

  • Tout texte doit avoir un ratio de contraste ≥ 4.5:1
  • Texte sur fond or : utiliser --text-dark (#1a1210)
  • Éviter les combinaisons rouge/vert pour daltoniens : ajouter des icônes

12.2 Taille minimale

  • Boutons interactifs : min 44×44px
  • Texte lisible : min 11px
  • Zone de clic carte : toute la carte

12.3 Réduction des animations

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}

12.4 Focus visible

*:focus-visible {
  outline: 2px solid var(--gold);
  outline-offset: 2px;
}

Checklist d'implémentation

Avant de considérer un écran comme terminé, vérifier :

  • [ ] Les couleurs respectent la palette définie (pas de #000000 ni #FFFFFF).
  • [ ] La typographie utilise les bonnes polices (IM Fell English / Courier Prime).
  • [ ] Les espacements suivent le grid 4px.
  • [ ] Les états hover/active/disabled sont implémentés.
  • [ ] Les animations respectent les durées standard (et steps() pour les sprites).
  • [ ] Pas de flash blanc ni d'effet agressif.
  • [ ] Le contraste est suffisant (≥ 4.5:1).
  • [ ] Les raccourcis clavier sont affichés.
  • [ ] Le texte est externalisé (i18n ready).
  • [ ] Le layout est testé en 1920×1080 et 1366×768.
